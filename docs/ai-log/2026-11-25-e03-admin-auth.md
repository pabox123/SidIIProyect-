   - `AdminAuthGuard` solo verificaba la firma del JWT y los roles embebidos en el token, **sin comprobar en MongoDB** si el administrador seguía activo (`isActive: true`) o si sus roles actuales habían sido revocados.
3. **Auditoría de controladores administrativos en `backend/src/modules/`:**
   - `AdminCatalogController` (`/api/admin/catalog` — 6 rutas: `GET /`, `GET /:contentId`, `POST /`, `PUT /:contentId`, `POST /:contentId/publish`, `POST /:contentId/withdraw`): protegido a nivel de clase con `@UseGuards(AdminAuthGuard)` + `@AdminRoles('catalog_admin')`.
   - `ReportsController` (`/api/admin/reports` — 2 rutas: `GET /revenue`, `GET /consumption`, JSON y CSV): protegido a nivel de clase con `@UseGuards(AdminAuthGuard)` + `@AdminRoles('report_viewer', 'catalog_admin')`.
   - `AuthController`: `POST /api/admin/auth/login` (público) + se agregó `GET /api/admin/auth/me` con `@UseGuards(AdminAuthGuard)`.
   - Ninguna ruta bajo `/api/admin/*` quedó desprotegida.

## (b) Ajustes e implementación realizados (Fase 2)

### 1. Autenticación de Administradores (`backend/src/modules/auth/`)
- **`LoginDto` (`login.dto.ts`):** Normaliza `email` con `trim()`.
- **`AuthService.loginAdmin` (`auth.service.ts`):**
  - Normaliza `email` (`trim().toLowerCase()`) y consulta `admin_users` usando `{ collation: { locale: 'en', strength: 2 } }` para aprovechar `ux_admin_email_ci`.
  - Verifica existencia, `isActive === true` y `bcryptjs.compare(password, admin.passwordHash)`.
  - Ante cualquier fallo (inexistente, inactivo o contraseña incorrecta) responde `401 Unauthorized` con el mismo mensaje genérico (`Correo o contraseña incorrectos`).
  - Actualiza `lastLoginAt` y emite JWT con `{ sub: String(admin._id), kind: 'admin', role: 'admin', email: admin.email, roles: admin.roles }`, 100% compatible con el frontend de Balanta (B-01/B-03/B-05).
  - Nunca devuelve `passwordHash`.
- **`GET /api/admin/auth/me` (`auth.controller.ts` + `auth.service.ts`):**
  - Protegido con `AdminAuthGuard`.
  - Consulta `admin_users` con proyección `{ passwordHash: 0 }` y `isActive: true`, devolviendo `{ adminId, fullName, email, roles, isActive, createdAt, lastLoginAt }`.

### 2. Blindaje de `AdminAuthGuard` (`backend/src/common/auth/auth.guards.ts`)
- Valida el token Bearer y su firma JWT (`401 Unauthorized` si falta o expiró).
- Exige estrictamente `payload.kind === 'admin'`; rechaza tokens de cliente (`kind: 'client'`) con `403 Forbidden`.
- Valida `ObjectId.isValid(payload.sub)` y consulta `admin_users` en MongoDB con proyección `{ email: 1, roles: 1, isActive: 1 }` (sin `passwordHash`):
  - Si el administrador fue eliminado o desactivado (`isActive !== true`), rechaza inmediatamente con `401 Unauthorized` aunque el JWT siga vigente.
  - Evalúa `@AdminRoles(...)` contra los roles vigentes en MongoDB (`403 Forbidden` si no tiene permiso).
- Adjunta la identidad verificada en `request.admin` y `request.user`.

## (d) Checklist de pruebas manuales (para Edwar)

1. **Login admin exitoso (`POST /api/admin/auth/login`):**
   - Probar con `admin@cineconecta.example` (o `ADMIN@CineConecta.example`) y contraseña semilla → `200 OK` con `accessToken` y `admin` (sin `passwordHash`).
   - Probar contraseña incorrecta o correo inexistente → `401 Unauthorized` con `"Correo o contraseña incorrectos"`.
2. **Sesión admin (`GET /api/admin/auth/me`):**
   - Con token admin → `200 OK` con datos del admin sin `passwordHash`.
   - Con token de cliente (`kind: 'client'`) → `403 Forbidden`.
   - Sin token → `401 Unauthorized`.
3. **Control de acceso en rutas administrativas:**
   - Con token de **cliente**, llamar `GET /api/admin/catalog`, `POST /api/admin/catalog`, `GET /api/admin/reports/revenue` y `GET /api/admin/reports/consumption?format=csv` → todos deben devolver `403 Forbidden`.
   - Con token de `reportes@cineconecta.example` (`report_viewer`), llamar `GET /api/admin/reports/revenue` → `200 OK`, y `POST /api/admin/catalog` → `403 Forbidden`.
   - Desactivar temporalmente un admin en MongoDB (`isActive: false`) y reutilizar su token vigente → debe rechazarse inmediatamente con `401 Unauthorized`.
